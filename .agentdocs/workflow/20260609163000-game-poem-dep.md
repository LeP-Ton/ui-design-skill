# game-theme 新增 poem 文字动画库依赖

## 背景与目标
- game-theme 新增文字动画库 poem（https://github.com/LeP-Ton/poem.git）作为依赖
- 在 standards/game.md 中描述 poem 的使用方法，作为 URL 类型依赖的标准示范

## 代码变更

### themes/game-theme/theme.json
```diff
-  "requires": ["css-variables"],
+  "requires": ["css-variables", "https://github.com/LeP-Ton/poem.git"],
```

### themes/game-theme/standards/game.md
新增「文字动画（PoemTextAnimator）」章节，包含：
- 安装方式（git clone 到 libs 目录）
- 核心 API（createTextAnimator / render / renderLines / splitTextToSpans / destroy）
- 游戏场景使用规范（剧情对话/技能名称/物品描述/标题横幅的推荐预设和参数）
- 注意事项（destroy 释放资源、性能模式跳过、animationClasses/animationResolver）
