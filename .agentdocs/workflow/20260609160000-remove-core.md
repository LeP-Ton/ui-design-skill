# 删除 core/ 目录

## 背景与目标
- core/ 目录下原有 adapters/ 和 standards/ 两个子目录
- adapters/（css-variables.md、tailwind.md）已在上一步删除
- standards/ 的 3 个文件（accessibility.md、interaction.md、responsive.md）内容 AI 本身就知道，对代码生成的增量价值极低
- core 层已无存在必要，整体删除
- 架构从 "Core + Theme" 简化为纯 "Theme 插件化"
