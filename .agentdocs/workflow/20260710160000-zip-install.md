# 主题安装方式改为 zip 下载，提升稳定性

## 背景与目标
- SKILL.md 原安装方式为"从统一主题仓库复制主题目录"，没有定义具体复制方式
- AI 执行时可能手动逐文件复制，导致遗漏空目录或深层文件（如 boss-theme-blue 缺了 assets/）
- ui-theme-hub 构建脚本已生成完整的 zip 包（含所有文件和空目录），利用 zip 包安装更可靠

## 约束与原则
- 安装方式改为 curl + unzip，一条命令完成
- zip 包由构建脚本保证完整性，避免 AI 手动复制的随意性
- 安装 URL：`https://le-p-ton.github.io/ui-theme-hub/packages/{theme-id}.zip`

## 代码变更

### SKILL.md — 主题搜索与安装

```diff
-- **安装**：从统一主题仓库复制需要的主题目录到本地 `themes/`，然后校验 theme.json 格式合规性
+- **安装**：从 GitHub Pages 下载主题 zip 包并解压到 `themes/`，然后校验完整性：
+  ```
+  curl -L https://le-p-ton.github.io/ui-theme-hub/packages/{theme-id}.zip -o /tmp/{theme-id}.zip \
+    && unzip -o /tmp/{theme-id}.zip -d themes/ \
+    && rm /tmp/{theme-id}.zip
+  ```
```

### SKILL.md — Phase 2 主题加载

```diff
-2. 若识别到的 theme 未安装，从统一主题仓库安装到本skill的`themes/`
+2. 若识别到的 theme 未安装，从 GitHub Pages 下载主题 zip 包解压到 `themes/`
```

### SKILL.md — 安装校验

```diff
-**安装校验**：安装 theme 后，校验 theme.json 格式是否合规：
+- 必需目录存在：`patterns/`（若缺失提示重新安装）
- 必需字段完整：`name`、`version`、`scene`、`tokens`
- tokens 6 维度完整：`color`、`spacing`、`typography`、`border`、`shadow`、`motion`
- color 基础字段完整：`primary`、`background.base`、`text.primary`、`border.default`
-- 若校验不通过，提示用户修复或更换 theme
+- 若校验不通过，提示用户修复或重新安装
```
