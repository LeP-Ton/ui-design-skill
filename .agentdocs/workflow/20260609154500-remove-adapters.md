# 删除 core/adapters/ 适配器文件

## 背景与目标
- core/adapters/ 下的 css-variables.md 和 tailwind.md 是 token → CSS 变量/Tailwind class 的映射模板
- AI 实际生成代码时不会读取这些模板做"变量替换"，看到 requires.adapters 声明就知道代码风格
- 适配器文件是给人看的参考，对 AI 无增量价值
- 删除后，requires.adapters 的语义从"依赖的适配器文件"变为"声明代码风格"

## 代码变更

### core/adapters/css-variables.md（删除）
整个文件删除，内容为 token → CSS Variables 的映射模板

### core/adapters/tailwind.md（删除）
整个文件删除，内容为 token → tailwind.config.js 的映射模板

### core/adapters/ 目录（删除）

### SKILL.md
```diff
-结合 token + adapter + pattern + standard 生成代码。
-- 使用 theme 的 token 值，通过适配器映射到框架变量
+结合 token + pattern + standard 生成代码。
+- 根据 `requires.adapters` 声明的代码风格使用 token 值（如 `["css-variables"]` → 用 `var(--xxx)` 引用，`["antd"]` → 用 antd 组件 + ConfigProvider 注入）
 - 遵循 theme 的 standards + 通用标准（见下方）
 - 禁止硬编码颜色/间距/圆角，必须使用 token
```

```diff

```


```diff
+- requires.adapters：声明代码风格（同时决定技术栈，如 antd → antd 组件库，css-variables → CSS 变量写法，tailwind → Tailwind CSS）
```

```diff

+- 前端：维护 Core（SKILL.md + 通用 standards）
```

```diff

+- 删除了 core/adapters/：AI 不需要映射模板，看到 requires.adapters 声明就知道代码风格，适配器文件无增量价值
```
